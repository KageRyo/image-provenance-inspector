# Validation fixtures

This directory contains small, traceable assets used to validate the actual
metadata and C2PA reader paths. Every committed binary must have a manifest
entry with its source URL, pinned source commit, license, and SHA-256 digest.

The committed `official-c2pa/C.jpg` is an upstream C2PA test asset from
[`contentauth/c2pa-python`](https://github.com/contentauth/c2pa-python). It is a
signed `c2pa.created` example, not evidence that the image was generated by AI.
The fixture test intentionally expects `origin=UNKNOWN` and
`editing=UNKNOWN`; the manifest proves that a credential is present, but does
not identify a camera source or an editing action.

## Adding real-world samples

Add images only when their redistribution is permitted. Prefer a public source
with a stable revision and record the provenance in `manifest.json`:

```json
{
  "id": "vendor/workflow-name",
  "path": "fixtures/vendor/workflow-name.jpg",
  "source_url": "https://example.org/source",
  "source_commit": "a pinned revision or release",
  "license": "the applicable license or permission",
  "sha256": "the file digest",
  "expected": {
    "c2pa_present": true,
    "actions": ["c2pa.actions.v2"],
    "origin": "CAMERA_CAPTURED",
    "editing": "GENERATIVE"
  }
}
```

Do not put private user images in this directory. Use the ignored
`fixtures/local/` directory for local validation, then add only legally
redistributable samples and their evidence-based expectations.
